# Classes Hub

## Project goal

Classes Hub gives students one transparent view of homework, grades, announcements, and deadlines that are scattered across platforms such as Brightspace, Ed, and Pearson.

## MVP scope

The first version is a TypeScript web dashboard for manually entering or importing assignments, viewing deadlines, tracking grade information, and receiving due-soon reminders. It includes a weighted grade report with what-if calculations.

## Future plans

- Add connectors for Brightspace, Ed, Pearson, and other course platforms.
- Add automatic syncing and calendar import/export.
- Add desktop or email notifications.
- Add visual analytics and planning views.

## Tech stack

- TypeScript
- Node.js and npm
- React
- Express
- Local JSON storage and CSV import
